# 放置流程离线策略

状态：纯离线候选，不接电机、不连接网页、不替换原服务，不是可运行的自动放置链路。

目标顺序：固定准备 -> D435 识别仓口与规划 -> D405 优先、D435 辅助视觉校正 -> 固定 Z 浅入 5 mm -> 夹爪保持。
桌面阶段不在候选策略中；夹持/调平判断标记为提示，不提供执行放行判断。实时电机反馈、停止、关节限位与路径检查不由本策略实现或绕过。

左侧规则：系统坐标的正 U 指向机器人左侧。以既有左侧目标中心 U 为参考，允许测得中心 U 在参考值至参考值减 8 mm 的区间，区间端点含在内。仓口轮廓和负载实际外廓仍需另行验证，此规则不等同于可入仓或碰撞检查结果。

双相机：对同一物理量优先选有效 D405，否则选有效 D435；D405 当前算法只能估计前端相对仓口的上下距离，不能把它当成姿态倾角。没有同量纲有效观测时返回空值，不生成运动命令。

验证：六个纯离线单元测试通过，包括阶段顺序、偏移方向和边界、优先级、无效数据、垂直距离与倾角不混用。还未与现有实时放置代码或网页接线，未验证标定、双相机测量质量、实物几何及碰撞，不能据此运行机器人。

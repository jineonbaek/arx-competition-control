# 双相机入仓阶段候选

状态：离线和模拟候选，未接入网页实机执行。不得将预览目标当作可执行指令。所有结果标记 executable=false，夹爪保持。

1. D435 仓口粗定位，生成几何预览与仓外关节路径。
2. 入仓精调只接受仓外对齐后采集、时间与其手臂及升降反馈配对、关节和高度与预期相符的 D405 帧。对位前的 D405 图不能复用为对位后的精调输入。
3. D405 部分红边可估计上下偏差，偏差不等于电池姿态；细调时重新计算仓口余量，右偏限制 0–8 mm。
4. 固定 Z 浅入 5 mm 为名义关节运动学预览，直到有对位后的 D405 观测前标记需要 D405；完整物体、两臂及环境碰撞未在此结果中验证。
5. d405_plane.py 对可能的电池近水平面生成不具执行权的候选法向；历史五帧角度不稳定。裁剪到前端之后当前帧多数无法拟合，不能用于自动调平。
6. d405_level.py 可以把外部提供的已验证 D405 电池姿态转成受限关节修正建议；目前没有经实机标定与验证的 D405 六自由度电池姿态输入，不能连接给执行器。

已知限制：当前生产 D435 外参是 CAD 名义估计；D405 外参只是离线候选；D435 当前电池画面被裁切。前一版完整离线规划仍依赖 D435 电池姿态，尚未改成 D405 已验证姿态，因此不满足本次最终实机执行要求。

## 无标定板的长轴候选

`d405_axis.py` 使用电池侧面候选、深度平面和视线交点估计可见长轴，并可检查静止状态下多帧是否一致；`d405_level.py` 可将该长轴转为限幅的离线调平建议。两者结果始终不可执行。

断电前 5 帧重复性：长轴倾角中位约 1.166 度，相对中位方向最大偏差约 0.552 度。旧方法误把不同黑色面当水平面，结果约 4–31 度。新方法仍只是假设所选平面是电池侧面，且 D405 外参的绝对精度没有实机校验；重复性不证明准确。原始帧经历断电，不可用于当前运动。

可用 `replay_axis.py` 对至少 3 帧配对 RGB-D 文件重算；需要在 PYTHONPATH 中包含本目录、机器人 web/src 和机器人项目根目录。输出的关节变化仅供研究，不连接控制器。

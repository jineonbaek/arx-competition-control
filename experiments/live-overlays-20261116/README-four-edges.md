# 电池可见面四棱透视拟合

`battery_edges.py` 是独立、只读图像模块，不导入控制、ROS 或 CAN。输入 RGB 帧，输出有序四角、四条直线的拟合残差、归一化平面到图像的单应矩阵，以及齐次消失点。前端方向由单应矩阵投影平面中线求出，不用包围框中线。画面中的对边允许会聚，不强迫平行；无实机相机外参/毫米精度标定声明。

先由暗色连通区域找候选可见面；上边取外轮廓支持点，左右边用鲁棒直线拟合，近侧横棱结合线段及面与前壁的亮度变化。四个角点由邻边求交，不跟随纹理、把手孔或夹爪曲线。

`PerspectiveTracker` 使用 5 个不同帧的中值与平滑；超过 10 px 的新位置需连续 3 帧支持后重捕获。短缺失最多沿用 0.6 s，画虚线并标记 held_recent，取消实时偏差输出；超时取消轮廓，不把过去的形状当新观测。重复帧不增加样本数。此阈值是显示跟踪参数，不是运动授权或物理精度容差。

实时输出保存在 web/public/camera-overlay/d405.jpg 和 d405.json，原 D435 标注保持。仅标记可见平面的四条棱，不声称重建完整电池 3D 包络。该模块暂不产生运动目标。

验证：7 项合成透视、无目标、错误几何、离群点、缺失、重复帧和重新捕获测试通过。2026-11-16 静止实机连续 25 个不同帧：25/25 原始四边拟合成功；预热后最大角点标准差原始 1.87 px，过滤后 0.58 px。此为像素稳定性，不是毫米定位精度。记录位于 reports/battery-lines-live-20261116-135822/report.json。

## 红框与电池边平行参考

`rim_edges.py` 使用相同直线支持点、邻边交点和透视四边形方式处理红框，并逐边稳定。D435 完整可见时输出四边与单应矩阵；D405 下边遮挡时只输出三条观测边，不把电池遮挡线当作框底边。蓝色 TOP 是红框外上边，`alignment.angle_error_deg` 为电池 1→2 相对 TOP 的有符号图像角差。它不是电机角度。

上层 `upper-placement-20261116/loaded_coarse.py --align-top` 默认只规划；加 `--execute` 才执行一次最多 1° 的相机视轴方向小转动，经当前 TCP/相机变换和 IK 求关节目标，固定名义 TCP 位置，保留夹爪。每次重新采图，不写死关节值，不修改厂家驱动。此入口是单次受限修正，尚不宣称整段闭环已经可靠收敛。

2026-11-16 试动记录：前两步反馈到位，图像角差曾由约 -4.8° 减至 -2.5°；第三步到位超时并保持，之后实时夹角约 -3.5°，因此未判定平行完成。原始记录在 reports/live-preview-20261116-140720-1af443d5、140809-5c4a6f19 和 140925-65bd81b6 对应目录。12 项图像几何测试、21 项上层执行/规划测试通过，测试通过不等于实物已调平。

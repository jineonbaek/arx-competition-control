# 实际装配网格离线过滤替换
状态：实现和两轮复验完成；11项本模块测试及8项依赖回归测试通过。动态融合仍未验收，详见 MESH_VALIDATION.md。
用户已授权替换并重跑。只改离线过滤与结果目录，不修改在线 TF、启动文件或控制接口。
1. 读取 URDF visual 网格（新增零件无 collision），合成关节零位、visual origin、scale 和 O 原点。传感器 mesh link 不作为测量 frame。
2. 5 mm 网格表面体素化，闭合表面填充；按部件处理，避免将整车空隙填成包围盒。比较 2/6 cm 近表面余量，记录离散误差。
3. 底盘刚性部分与 head_113 子树分组；头部组按实际时刻候选 D(t)*inv(D_CAD) 运动。近似不描述立柱沿高度弯曲，双臂保持录包对应零位。
4. 单测单位、链式变换、空隙保留、内部/表面与余量、动态头部运动。独立输出 mesh-flex-scenes 和 offline-flex-mesh，保留 box 结果。
5. 两轮 24 时刻×3窗口/余量变体，联合估计默认及强度敏感性；比较约束覆盖、留出残差和基线/候选地图一致性。过滤变化不等同融合精度提升。

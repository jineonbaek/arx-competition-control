# 双 MID360S：CAD 约束离线柔性联合估计验证
更新：交付包实际 STL 网格过滤替换及两轮复验已完成，详见 [MESH_VALIDATION.md](MESH_VALIDATION.md)。下文保留包围盒版本历史结果。
日期：2026-11-05。已实现并在 NUC 两轮已有记录上运行；尚未通过连续动态融合有效性验证。未接 Nav2，未发送运动指令。本次仅离线处理，原始场景数据留在 NUC。

## 几何与过滤
采用用户确认的 CAD，坐标 O 在底盘整体外接圆圆心的地面投影，X前/Y左/Z上。
- 底盘安装面中心 (197.330,-0.003,281.000) mm；光学原点 (197.330,-0.003,234.000) mm。
- 头部安装面中心 (6.536,0.997,1239.790) mm；光学原点 (6.536,0.997,1192.790) mm。
- 两台倒装 Rx(pi)；IMU 原点分别 (208.330,-23.293,278.120)、(17.536,-22.293,1236.910) mm。
- CAD 相对光学/同型 IMU 坐标变换 p_head=R*p_bottom+t，R=I，t=(190.794,1.000,958.790) mm。这是静止先验，不是固定拼接变换。
- 仅收到尺寸表，无精确碰撞网格。过滤使用保守整车盒 x[-.401657,.422010]、y[-.380085,.380169]、z[.03,1.268] m，并比较 2/6 cm 余量。头部过滤按候选动态姿态变换，不能称为精确 CAD 网格自过滤。

## 实现
cad_scenes.py：各雷达已由自身 IMU 去畸变的 cloud_body 位于其 IMU 系，按扫描结束时间和各自 LIO 补偿成局部子地图；多帧静态支持、平面约束、空间分块留出。比较 0.5/1 s 窗口。实际点云窗口覆盖不足、配准残差大、支持不足、初值敏感或几何退化则拒绝。

flex_core.py：5 Hz 稀疏离线批量平滑器，同时估计底盘位姿修正及头部相对 CAD 的六维柔性偏移；约束包括底盘 LIO 位姿先验、头部 LIO 相邻增量、共同场景相对位姿、柔性变化速度/加速度软约束。没有简单平均两路里程计，也不把相同原始 IMU 重复作为独立观测融合。场景因子按真实时间插值评估。

退化处理：信息矩阵弱方向投影、粗差拒绝、优化后残差门控；只有近期 ±0.6 s 的全秩且一致场景约束允许候选输出。其余节点严格回退到底盘单 LIO。候选轨迹、门控输出、柔性估计与 fallback 标记分别保存。此退化处理针对共同场景因子，尚不检测底盘单 LIO 自身跟踪失效。

run_offline.py：偶数场景训练，奇数场景留出；地图对比使用同一底盘点集、共同有效匹配集合，排除参考地图前35 s与验证段重叠。参考地图仍来自同次底盘 LIO，因此是相关的一致性诊断，不是精度真值。

## 重跑结果
默认：1 s 窗口、2 cm 过滤余量、柔性约束强度1。两轮没有可用的精确首尾真值。

地图一致性没有改善。头部柔性幅度是估计候选，可能包含 LIO 漂移/配准误差，不能当作实际机械形变量。留出相对场景第一轮平移偏差有两处改善、一处变差；第二轮三处改善，但数据量不足，而且留出场景仍共享 LIO 去畸变，不能据此认定连续融合可靠。

敏感性：柔性强度0.5/1/2均收敛；头部最大平移候选第一轮37.499/35.146/32.990 mm，第二轮42.208/37.349/31.951 mm，说明幅度受先验影响。6 cm过滤余量下第二轮回退比例升至99.481%。0.5 s窗口两轮均仅3/24个场景通过初筛；1 s窗口分别6/24和5/24。

## 验证与限制
8项合成测试通过：坐标/过滤、弱方向投影、无场景严格回退、已知柔性、粗差拒绝、低秩不授权输出、冲突观测后验门控、实际时间因子。8套轨迹结果均有限、时间递增，fallback节点与底盘基线逐元素一致，优化均收敛。
代码复核后修正：场景时间吸附、参考/验证重叠、缺少后验一致性门控、实际点云窗口完整性、旧配准种子带来的留出信息泄漏，并重跑全部结果。静态复核无剩余阻断问题。
复核小限制：优化旋转用CAD相对旋转向量插值，留出评估用四元数插值；变化轴时有微小模型差异，后续应统一。
测试须设置 PYTHONPATH=dual_flex；未设置时测试导入失败，设置后8项全通过。

这不是原始双 IMU/点云紧耦合 LIO，不是实时动态融合。5 Hz不能解析2.5 Hz以上头部振动；权重和门槛为实验参数，未校准协方差，相关性未完整建模，切换连续性未批准用于控制。尚未生成可用于导航的动态融合地图或接入避障。下一步需提升连续共同场景约束与可观测性，并加入更高频柔性模型/底盘LIO失效监测，再作独立真值验证。

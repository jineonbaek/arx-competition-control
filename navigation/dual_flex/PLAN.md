# CAD约束双LIO离线柔性联合估计

用户授权实现离线验证，不接Nav2、不发送运动命令、不重启在线传感器。

1. CAD几何：以地面O为base参考，底盘与头部原点用IMU坐标，分别为[.208330,-.023293,.278120]和[.017536,-.022293,1.236910]m，Rx(pi)。CAD仅静止先验。头部动态相对位姿单独估计。仅有尺寸表，精确碰撞网格缺失，用保守包围盒及2/6cm两种余量验证过滤敏感性。
2. 重跑共同场景子地图：逐扫描用自身LIO补偿，不固定合并双云；头部过滤使用候选动态位姿及余量；静态多帧支持；空间留出。显式提供配准信息矩阵特征方向，稀疏/不稳定/大残差观测拒绝。
3. SciPy稀疏批量平滑器，5Hz状态节点：底盘SE3位姿、头部相对CAD的平移和旋转6维偏移。底盘LIO位姿保守先验、头部LIO相邻增量、相对场景因子、柔性变化速度/加速度软约束。不额外融合相同原始IMU，避免把已由LIO使用的IMU当独立观测重复计入。IMU用于离线振动验证。
4. 退化门控：几何弱方向不引入虚假强约束；缺可信相对观测时输出回退到底盘单LIO，柔性只作未验证诊断。联合候选与最终门控输出分开记录。所有噪声/模型参数都是验证参数，不输出已校准协方差。
5. 合成测试：已知柔性运动、退化方向投影、异常拒绝、零场景下回退、坐标逆变换/车体过滤；随后用两轮录包评估连续性、停稳变化、相对场景留出残差、窗口/包围盒余量/柔性强度敏感性。没有外部真值，不声称绝对精度提高。

状态：离线实现和两轮验证完成；连续动态融合有效性尚未通过，详见README.md。源数据只留NUC。此版本不是原始点云/双IMU紧耦合系统，也不替代最终动态估计器；先验证高质量相对约束能否提供收益。

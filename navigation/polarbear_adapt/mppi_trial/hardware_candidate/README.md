# 隔离底盘候选：仅完成离线验证

此目录不被桌面启动脚本、网页或现行底盘进程引用。禁止把编译成功等同于已通过实车验收。

唯一行为修改：任一速度轴反向时，该轴减速到零、保持0.2秒，其他轴继续跟踪；全局停车、0.8秒制动等待、0.25秒断流、未标定及非法输入保护保留。平移仍按二维向量合成限加速度，不按两轴各自放宽上限。

离线测试使用真实ChassisMotion实现，无ROS、CAN、HTTP或电机接口。原版在微小修正反向用例中失败；候选通过持续纵向跟踪、逐轴反向、合成变化率和全局保护四组行为测试。

NUC编译时仅复制原版lift_controller_web.cpp、slow_lift_config.hpp及command_lease.hpp到本目录，生成独立名称的lift_controller_mppi_candidate。不会覆盖web/hardware/build/lift_controller_web，也不自动启动。

重放工具：上级目录replay_driver.py，输入本轮closed-current-live.json，用同一400Hz时钟分别运行原版和候选。重放假设HTTP请求在样本时间被接收且始终ready，不能替代实际DDS接收和CAN发送的观测。

用户最新实测：网页SDK原值0.3能够缓慢移动。尚无对应SI稳态速度、起步阈值和全向组合测试，不据此修改sdk_preview.py，也不对任意非零输出统一施加0.3最小值。

实际接入前还需：保存原驱动回退副本、确认底盘/升降状态；在单一控制权下记录实际SDK话题及CAN输出，完成起步、连续低速、短目标收敛和停车测试。候选尚不应直接作为默认导航控制器。

# D405电池夹持、姿态与滑移判断设计补充

2026-11-15。用户补充“D405判断电池状态、是否正确夹到、姿态是否正常”。本文件补充局部自主入仓设计的G09持物门控；参考驱动RGB匹配、持物时序判断及G09接入已离线实现，未连接实机；实现边界见 `docs/held-docking-offline.md`。本轮不采新图、不运动、不自动夹紧/松爪、不推送。

## 职责与现有缺口

D435主定位电池仓；D405主观察电池相对夹爪的状态。D405不需要看全电池仓，也不强制看全电池；应判断关键夹持区域是否足够可见。D405局部不可见不影响D435的红框识别结果，但如果缺少必要持物证据，对应携物动作需保持，不能把“辅助相机”解释成持物证据可忽略。

源码核对：

- `agent/motion_feedback.py`的PickMonitor明确不证明可靠持物，闭合到位/受阻后进入awaiting_hold_verification。
- `agent/placement_backend.py::load_held`从既有抓取位姿与计划终点推算持物关系；`_check`检查夹爪原始反馈范围。这不能替代运动后的新视觉观察。
- `web/src/foundationpose_preview.py`当前是完整电池ROI、RGB-D与短时GPU估计流程，不是已接通的部分可见实时夹持监测器；不能直接标为本能力已完成。
- `web/public/cad/battery-grip.json`已有把手孔40×14mm、横梁、凸起和工具接触参考点；夹爪毫米开口尚未实机标定。原始夹爪值不能直接当作毫米开度或夹持力。

## 分别判断什么

| 维度 | 正常证据 | 异常/不确定情形 |
|---|---|---|
| 电池存在 | 夹持区域出现匹配CAD/把手特征，身份连续 | 观测充分但无电池为absent；被遮挡为unknown，不能混同 |
| 夹持位置 | 可见夹指、孔洞/横梁与预期夹持区关系一致，未只夹住边缘或夹空 | 单侧挂边、夹偏、夹在壳体错误位置；看不见关键接触区则unknown |
| 相对姿态 | 可观测的电池轴向、倾斜、翻转与预期持物关系匹配 | 偏斜、倒置、错误朝向；对称或特征不足保留多解 |
| 动态稳定性 | 不同曝光的连续帧支持电池相对工具关系不变，误差上界在本阶段预算内 | 持续下滑、相对扭转、突然跳变；模糊/失跟踪时不宣称稳定 |
| 夹爪反馈一致性 | 夹爪位置/状态与视觉、阶段回执一致 | 夹爪到位但视觉夹空，或视觉有电池而反馈/夹持关系冲突 |

“视觉符合预期”不等于已测得夹持力。D405不能凭一张图证明隐藏接触、夹紧力或承载能力；可靠携物资格仍需视觉、夹爪反馈、经过验证的抓取/承载证据共同成立。看见电池、正确夹到、姿态合格、允许携物移动分别输出，不能共用一个confidence或green=true。

## 观测与坐标

第一版在深度未配置时使用彩色图像中的把手孔边、横梁、夹指轮廓及可区分朝向的CAD特征。先检测/分割并屏蔽背景、夹爪遮挡，再跟踪可见对应点与局部轮廓。未配置深度不参与评分，也不因零深度产生“空夹爪”结论。以后若使用D405深度，须单独通过对齐、单位和时序门控，不能悄悄切回旧RGB-D假设。

可以在关键特征充分、对应唯一且内参适用时求RGB/CAD位姿，但必须输出可观测自由度、歧义候选与误差界。只看见一个孔或一条边时，不承诺完整6DoF或毫米级夹持深度；不能把把手对称、180°翻转或被挡住的凸起方向强行判正常。预测位姿可帮助跟踪，但不能用预测本身作为“观测吻合”的证据。

复用既有D405手眼与TCP，并保留它们的验证状态。度量链为：

`T_grip_from_battery = inverse(T_wrist_from_grip) × T_wrist_from_D405 × T_D405_from_battery`

滑移判断优先在grip或D405坐标系内比较同一电池的相对关系。D405随右腕运动，正常转腕时相机和电池可以共同运动；不能因背景改变、世界姿态改变或J6变动判为滑移。夹指会随开合运动，需依据当前夹爪状态更新可见性/遮挡模型，不能把夹指运动当成电池滑移。完整世界姿态还需配对的FK、升降及局部重力坐标，不能由腕相机的单帧2D框直接代替。

正确夹持基准来自经过验证的预期抓持区域和本轮实际观察，绑定电池CAD、抓取ID、夹爪配置、手眼/TCP hash、控制/启动代次。不能把第一帧、当前任意姿态或一次历史grasp_confirmed自动设为“正确”；稳定夹偏也必须判为不合格。已经发现的漂移不许通过在线更新基准清零，只有新抓取事件与独立合格证据才能建立新基准。

## 输出与精度合同

输出建议为：

- presence：present / absent / unknown。
- engagement：visually_consistent / visibly_incorrect / unknown。
- pose：matched / misaligned / ambiguous / unobservable，并分项报告可观测的平移/角度、坐标系和不确定性；不可观测项用null，不能填0。
- stability：stable_observed / slip_suspected / unknown，附独立帧ID、相对位移/角变化及时间窗。
- grip_feedback：consistent / conflicting / unavailable；原始夹爪值保留原始单位，力证据未安装/未标定时明确unavailable。
- holding_eligibility：eligible / blocked / unknown，由G09联合抓取承载证据和当前动作合同决定；附具体阻断原因，不由单幅图的分数直接决定。

报告每项证据的时间、可见区域、模型/标定版本与有效期限。不同曝光才计新证据；重复、迟到、未来时间或快照不匹配不凑稳定帧数。断流、重新启动、换物、人工开合、换夹指、手眼/TCP变化使相关旧证据失效。

阈值按阶段和本次电池全包络净距/停止余量推导。转动误差要计入电池远端位移，不能只看夹持点平移。只有估计误差的可靠上界在剩余预算内，才可写stable_observed；确定的异常可直接触发停止，不必等满多个异常帧。测量模糊落在通过/拒绝之间时为unknown，不用一个通用2mm阈值掩盖窄仓口要求。不可见方向不能报告零漂移。

## 如何进入自动流程

1. 运输/局部搜索前：结合最新抓取回执、D405可见夹持关系、夹爪反馈与承载证据检查G09。
2. 每次底盘、升降、转腕或仓外纠偏后：停稳重测，检查电池相对工具是否改变，必要时重算负载包络和入仓姿态，不盲目执行固定J6=-90°。
3. 入仓前与入仓中：按本阶段观测时效和停止包络持续监测。仓口或夹爪造成遮挡时输出unknown，并按有效证据期限受控停止；不强制D405看全框，不把D435的仓口稳定替代持物稳定。
4. 疑似滑移/夹偏/姿态错误：中断下一运动段并请求保持。不得自动加夹紧力、重新开合、摇晃或抬升来“试夹牢”。只允许无运动重观测；额外观察动作也必须独立满足持物与路径门控，不能因看不清就移动未知负载。
5. 正常释放：从持物监测切到release_requested / released_verified等阶段。释放造成的相对运动或空夹爪不是运输滑移；但仅看到夹爪空了也不能证明电池已放稳。释放结果未知仍锁存，由D435留仓证据、夹爪回执和G15–G17独立核对，不能自动再次开合。

D435可提供电池可见部分与仓口的交叉检查，但必须时间配对并考虑共享标定误差；重复预测或两份来自同一旧快照的结果不能冒充两路独立证据。D405关键区域不可见、D435也不能补足时，保留unknown和动作限制，不自动询问一连串相同问题，也不自动给出“夹持正常”。

## 网页与验收

网页在D405画面上叠加把手孔、夹指/接触区、预期与观测姿态，显示“视觉夹持符合 / 夹空 / 夹偏 / 姿态异常 / 疑似滑移 / 遮挡，暂不能判断”等分项状态及可解释原因。是否允许下一动作由统一门控显示，不能以绿色框或识别置信度暗示夹持力已经验证。

追加A47–A58共12项拟执行离线场景，见主验收CSV；包含正确局部夹持、夹空、稳定夹偏、对称多解、正常转腕、真实滑移、遮挡、重复帧、深度禁用、基准被改写、反馈冲突及释放阶段。它们是验收设计，本轮没有运行新识别模型或实机验证。

# 仓口右臂控制接口：接入准备与边界

新增 `agent/cabinet_controller_bridge.py`，提供已有 Controller 的进程内右臂时序轨迹适配。它调用已有 `reserve_motion/start_trajectory/poll_trajectory`，独立停止使用 `adapter.arm_stop('right')`，不构造 ROS、SDK、CAN 或相机对象。

2026-11-15 按用户“升级推送并测试”指令，已升级在线网页观察服务，并增加只读就绪状态和固定拒绝测试接口。没有运动 HTTP 入口，也没有把 OfflineCabinetRun 改成实机执行；该流程仍严格只接受 SimulationExecutor。本模块也没有实现或安装实际物理证据提供器。默认调用会在申请控制权前拒绝。因此不能把本轮单元测试通过解释为已经完成实机放置或已具备物理执行许可。

## 已覆盖的接口行为

- 只支持右臂 `outside_align/insert/retreat` 时序轨迹，沿用逐段 quintic 标量插值协议。没有升降、底盘或松爪动作入口。
- 轨迹、运行/启动身份、代次、资产/抓取身份、策略、控制代码和配置 hash 绑定到一次请求。
- 启动前及运行中调用受信任的进程内物理证据提供器。它必须核验该阶段所有 G01–G20 要求；模拟 Decision、人工口头允许、缺失证据或过期回执均不构成许可。
- 许可必须带严格小于净距的已验证误差上界及保留量，正常/停止包络和实机停止行为必须由提供器实际验收。当前没有这些证据，因此默认拒绝。
- 一次完整时序交给已有驱动，不把它拆成临时连续关节目标。启动确认后复查许可与控制权；确认超时或结果不明锁存恢复状态。
- 独立停止请求不经过普通运动反馈/观察模式门控；没有新鲜、连续、不同的双臂和机体测量，不交还控制权。停止服务接受或轨迹参考完成均不等于到位/停稳。
- 反馈/驱动在交权前变化时，原停稳证据失效；确认结果不明时，即使之后停稳也保留控制权和恢复锁，不自动重放。
- 人工停止锁存后不能重用该桥对象启动下一段。此对象只管理一个段；完整流程仍需要外层持久化意图、证据刷新、父子任务所有权与恢复流程的正式接线。
- 交权与取消的状态提交串行化。若已提交经核验的单段到位/交权，随后并发到达的取消不撤销已完成的到位事实，但 `cancellation_requested` 仍锁存；未来父流程必须在启动任何下一段之前检查该字段，不能只看 `completed`。

独立目录的 Controller 新增可选 `expected_driver` 参数，保留原调用方式，并把许可中绑定的驱动代次一直传到驱动的原子启动检查，防止停止之后重新绑定新代次而复用旧许可。在线目录较新的 Controller 已采用窄补丁加入该参数，保留原导航和比赛任务功能。本次没有把独立目录中较旧的整个 Controller 覆盖到在线目录。

## 信任边界

`PhysicalApproval` 是可信服务器代码内部的接口合同，**不是物理标定算法、密码学证书或网页 JSON 模型**。不得从网页参数、模型回复或“现场有人看着”直接填充它。若未来提供器把普通布尔值当作实测事实，传输适配层无法纠正这种错误。

提供器必须实际完成：当前夹持姿态/滑移与可靠承载、D435 到基座及 TCP/夹物的误差界、完整负载与停止包络、原停止服务的物理行为、精度/支撑条件、运行中场景与手动接管监督。现阶段均未由本适配模块自动认证。

接口中出现的策略数值由调用方明确传入，并绑定到物理许可；测试中的数值只属于测试夹具，不是实际运行参数。接口代码没有后台轮询或心跳线程，外层需要持续调用 poll；进程失效时实际电机行为仍取决于既有驱动租期机制，必须纳入带载停止验收。

## 当前实机阻断

已知完整固定 Z 入仓计算返回“电池包络会碰仓口边缘”；名义最小净距约 -0.27 mm。这一拒绝保持有效。调平的名义包络计算不能批准完整入仓。

保留原扭转角的另一候选使电池竖向包络约 85 mm，超过 79 mm 仓高，已标记不用于放置。完整调平候选需要同时调整俯仰和滚转，但还没有实机执行和停止验收。

原桌面/红圈放置流程与仓口插入流程不同，本次不调用原有下降/松爪流程。原工程与在线控制目标未因接口升级改变。源码按用户后续明确授权发布在独立功能分支，不合并主分支。

## 在线诊断与验证

- GET `/api/cabinet-controller`：现有会话 Cookie 保护，只报告接口是否安装、驱动绑定协议是否支持、缺少物理提供器；`execution_enabled=false`。
- POST `/api/cabinet-controller/probe`：现有 Cookie、同源、JSON 和请求大小限制；只接受 `{"op":"admission_probe"}`，不接受目标、使能或审批。固定当前反馈起点，不注入提供器，测试在申请控制权前被拒绝。忙碌的运动、底盘或比赛任务禁止测试。
- 以上接口没有驱动使能、运动目标、底盘、升降或松爪功能。诊断不会改善或批准物理精度。

独立工作树完整回归 agent370、web441、前端50，共861项通过，包括32项桥接测试和8项就绪测试。在线较新源码的独立候选通过96项控制、桥接、HTTP、比赛所有权和导航回归；测试使用 FakeAdapter。候选沿用在线版本原有预览测试夹具，补充新诊断 HTTP 测试，不用独立分支的新预览协议要求替代线上旧预览协议。

只重启网页观察服务；既有两臂驱动、升降驱动和相机进程身份未变。在线真实诊断返回缺少物理提供器，在申请控制权前拒绝，测试前后控制代次不变，双臂和机体反馈新鲜，三路 JPEG 解码成功、帧序号增长。没有下发运动、驱动使能或实物放置。

首次升级检查遇到观察订阅刚启动、轨迹状态尚未到达，实际提前拒绝为“No idle trajectory driver”，已自动回退。只读 ROS 状态核实驱动为 idle/ready，增加订阅发现等待后重新升级，正确命中缺少物理提供器门控；没有绕过驱动或物理门控。

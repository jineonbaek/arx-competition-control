# 独立调试与比赛合并模式

## 调试入口

1. `/navigation-debug.html`：只读取雷达地图、底盘位置和导航路线状态。路线执行、定位调整仍由导航端处理，本页不会启动抓取或放置。
2. `/visual-docking.html`：独立视觉定位与固定底盘放置，不需要导航 9985 服务、到点通知或地图 TF。
3. `/map.html`：比赛总控，保留导航、抓取、运输、导航到柜前、视觉修正底盘和真实放置的自动串联。

## 一步一步调试

先用导航端或手动把底盘调到柜前并停稳，然后进入视觉调试页。

- 点击“只做视觉定位”：读取当前 D435 仓口图和坐标，显示与已记录参考的前后、左右和偏航偏差。完成后等待下一次人工操作，不移动底盘、机械臂或升降。
- 可先在人工确认的正确柜前位置点击“记录当前位置和画面”，作为参考；不会用任意当前画面自动替换参考。
- 固定底盘后，勾选通道确认，再点击“机械臂放置并返回”。本轮重新读取视觉证据，不直接复用上一次定位的旧帧。D435 偏差必须满足当前参考，随后复用 D405 水平微调、+X 160 mm 推入、松爪和返回。
- 放置高度参考为 0 rad，此调试入口不移动升降；抓取 A/B/C/PlanD 高度配置不变。
- 点击停止只取消本轮调试。重复请求不会重复推入或松爪。机械臂尚未完成停止清理时保留控制权，避免下一轮与原动作重叠。

独立调试不登记导航 worker、不伪造导航到点通知，也不发送导航完成/失败回执。底盘停稳的依据是操作者明确确认固定底盘，加上本轮配对观测要求底盘无活动输出；它不冒充导航端的地图定位和实测停车回执。

## 比赛模式

比赛仍通过真实 `point_2` 到访进入 `NavigationPlacement`：D435 修正底盘并确认停车后，调用与调试模式相同的 `FastVisualLevel.start_owned` 机械臂放置执行器。完成插入、松爪、返回和控制权释放后，才由比赛流程发送导航完成回执。

因此调试入口拆开，执行核心复用；不需要在比赛前把两套运动代码重新拼接。

## 接口

`GET /api/placement-debug` 返回当前独立调试状态。

同源网页会话可提交 `POST /api/placement-debug`：

- 只定位：`{"op":"observe","request_id":"唯一编号"}`
- 放置：`{"op":"place","request_id":"唯一编号","expected_epoch":当前指令版本,"environment_clear":true,"base_fixed_confirmed":true}`
- 停止：`{"op":"cancel","request_id":"当前调试轮次编号"}`

网页打开只读状态；不会自动采集识别或执行运动。调试状态明确包含 `moves_chassis=false`、`sends_navigation_receipt=false`。

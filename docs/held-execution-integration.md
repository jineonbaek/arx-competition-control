## 实现与明确边界

- `/api/cabinet-execution` GET/POST接入服务器持有的CabinetExecutionTask，现有Cookie、同源、JSON和大小限制生效。只接受当前模型开始或取消，不接受关节、目标、容差、增益或许可。
- 服务端从新D435彩色帧定位红框，用现有TCP、当前升降及机械臂模型计算轨迹，通过ControllerBridge进入实际Controller时序接口。离线模拟器保持独立。正向回归使用真实桥接逻辑和模拟电机，不构造ROS/CAN。
- 入仓之前的姿态/高度对齐属于outside_align，入仓轨迹保持Z和姿态，单段限45s、关节3deg/s和6deg/s²、TCP12mm/s和25mm/s²。不能用预览中其他升降高度替代当前实测升降。此任务不控制底盘、升降或松爪；完成结果为completed_hold，battery_placed始终false。
- 5mm到位判断比较实际FK与最终视觉TCP目标，包含IK残差。中途人工命令、左右夹爪/左臂/机体/升降或配置变化会作废整轮。取消不等待审批锁，结果未知保留恢复状态，不自动重放。
- **当前没有生产物理证据提供器，execution_enabled仍为false。接好了任务和传输入口，不等于完整实物自动放置已验收或已放行。** 未把人工接受5mm或图像重投影误差写成PhysicalApproval。

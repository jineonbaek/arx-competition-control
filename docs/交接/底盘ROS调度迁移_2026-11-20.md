## 接口与进程边界

调度器与硬件运行域191。导航域192使用独立rclpy Context进入191，避免将导航图整体跨域。

| 接口 | 类型/用途 |
|---|---|
| `/chassis/command` | `arx_chassis_interfaces/msg/Command`，速度与任务结束 |
| `/chassis/command_result` | `Result`，明确接收/拒绝原因及对应输出序号 |
| `/chassis/state` | `State`，活动来源、调度器/驱动实例、准备状态与实际应用SDK/序号 |
| `/chassis/manage` | `srv/Manage`，注册、停止、任务清理、维护租约和心跳 |
| `/chassis/ordered_output` | `Output`，调度器至驱动的唯一速度输入 |
| `/web/chassis/output_status` | 保留驱动JSON状态兼容现有观察器；不是运动入口 |

“接收成功”与驱动“已应用”分别由结果及状态中的应用序号表示，不把发布成功视为实车运动完成。
驱动通过参数服务只在保护、零输出且原指令过期后绑定新的调度器实例；旧实例和旧序号拒绝。

## 保留的控制规则

- 最后一条通过校验的指令生效，不增加来源优先级。
- 网页有效期1秒；导航/手柄各300ms；转发保留原始到期时间，来源时钟略快也不得延长超过其租约。
- 网页SDK合成平移上限1.6，分轴X0.92/Y1.6，自旋1.8；导航入口0.8，执行档位0.6/0.225；手柄入口合成平移/自旋2。SDK自身分轴饱和不变。
- 正常松键清零，新按键立即爬升。取消固定反向等待，仍有平移1.6 SDK/s、旋转加速2.4/减速0.8 SDK/s的斜坡。导航自身1.6/1.6爬升不变。
- 急停、故障、超时走原保护路径；普通任务结束只清理本来源。
- 维护会话2秒心跳租约，到期撤销能力，旧会话不得作为普通来源返回。
- 浏览器依据NUC反馈时间加本地单调时间产生指令时间，传输延迟保守计入剩余有效期。
- 调度器重启后同一旧任务代次持续拒绝，需释放并建立新代次。网页重启可恢复同一浏览器身份绑定，但不会重播缓存目标。

实现取舍：管理操作合并为一个有类型的`/chassis/manage`服务。旧内存调度类保留用于非ROS单元测试配置；实机配置选择ROS，RosAdapter旧直接底盘发布入口明确拒绝，不作为在线回退出口。

## 日常管理与回退

只重启调度器：`systemctl --user restart arx-chassis-scheduler.service`。
此操作不重启底盘SDK，不触发升降初始化；旧任务需要重新建立代次。
日志：`journalctl --user -u arx-chassis-scheduler.service -n 50 --no-pager`。
刷新网页加载新JS。

回退助手：`/home/arx/arx-competition-control/chassis_runtime/rollback.py`。
它要求底盘及作业空闲，停止独立服务，恢复切换前源码和驱动，重启网页/手柄/硬件。**回退会重启底盘并触发升降初始化，执行前需重新确认现场允许。**本轮未执行回退。
不要同时启用旧Controller输出与独立调度器，不启动第二个SDK/CAN5实例。恢复旧版本应使用完整回退，不只改`chassis_backend`。

后续需现场单独验收：网页与手柄的非零操控、正常/特殊段导航、任务交接、实际加减速与制动效果。

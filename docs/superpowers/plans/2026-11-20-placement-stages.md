# 独立放置步骤与 Z 观测实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Preserve the existing isolated workspace and previous changes. No automatic Git commit/push or physical motion testing.

**Goal:** 放置页独立执行预观测、D405 修正、入仓，支持修改预观测点和控制 Z。

**Architecture:** 新 PlacementStages 只控制右臂，复用 Controller、DockingMotion 与 CurrentAxisPush。独立 RGB-D 几何模块从实际红框内沿和深度恢复仓口高度基准；页面单独显示模型 Z、仓口参照 Z、目标和误差，观测不触发运动。

**Tech Stack:** 现有 Python/NumPy/OpenCV、原生 JavaScript、Node test、unittest。

**Spec:** 本文件以下约束；用户明确三个独立步骤，仓口中心离地 630 mm 暂定，允许自行修改观察点。沿用用户此前直接执行、不重复设计审批的偏好。

## Global Constraints

- 仓口高度默认 630 mm，标注暂定并允许修改。
- TCP 模型高度包括实际升降反馈；视觉高度通过固定仓口的实测相对几何估计，缺测不能冒充真实高度。
- 底盘、升降、左臂、夹爪均不由新独立动作改变；入仓保持夹持，不自动松爪或返回。
- 三阶段可从当前位置独立启动，不检查另一个阶段是否完成，不自动串联。
- D405 默认 Z 修正；水平 Y / Y+Z 可选。Z 单独控制固定 X/Y 和末端朝向。
- 页面加载只 GET；参数保存、采集、运动分别明确按钮触发。禁止网页发布或验收过程自动发机械臂动作。
- 保护当前源码与其他同学修改；按哈希备份部署，只重启网页，不重启硬件。

## Review Focus

- 底盘移动或相机过期时，旧视觉高度不能继续标为实时实测。
- 红框只有部分棱时，只计算有实际相对边线支持的维度，不能补出被遮挡的棱。
- 保存关节点与采集画面不能发送运动，非有限数/超限点拒绝且旧设置保持。
- 独立操作的取消、重复请求、失败清理保持夹持，不能错误进入下一阶段。
- 页面正在编辑时轮询不能覆盖输入；不可把模型毫米高度与升降 rad 混淆。

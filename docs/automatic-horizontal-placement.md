# 一键自动水平放置

入口：`http://192.168.58.14:9983/placement.html`。

1. 先让右夹爪可靠夹住电池，底盘停稳，D435能看到完整红框。沿用现有抓取TCP和相机标定。
2. 选择当前演示电池仓或比赛上排中间仓口。预览按钮只识别，不运动；开始不要求事先点击预览。
3. 点击“开始自动放置”，一次完成 D435定位 → 仓外对齐 → 固定Z水平入仓 → 松爪并确认张开 → 沿原方向退出仓外 → 放置确认。
4. 页面显示阶段与日志。只有电池识别、位置核对和稳定确认都完成后，才显示 completed / battery_placed=true。

## 动作与确认

- 入仓继续使用原有RGB/CAD定位、左半区目标、TCP和轨迹规划，不使用旧版“下降到支撑面”动作。
- 通过现有Controller的控制权、轨迹回执及ArrivalMonitor接实机；不伪造独立ControllerBridge所需的PhysicalApproval。
- 水平入仓复用原执行桥接的关节到位容差0.002 rad及0.3秒静止窗口；仓外TCP到目标的三维总距离不超过5 mm。不再套用抓取的5 mm/轴、旋转误差分量1.5°监控。旧下降放置的30 mm水平、3 mm高度、8°姿态配置不变。
- 轮速静止容差为±0.05，使用现有轮速反馈的原单位，允许编码器零点残差；反馈失效及实际底盘运动仍拒绝。
- 松爪复用现有夹爪打开目标及反馈参数。未收到实际张开反馈，不后退。
- 后退从实际插入到位的TCP开始，沿本次入仓轴反向退出本次行程，保持Z和姿态；仍用现有CAD路径检查。
- 放置确认复用抓取识别模型（Grounding-DINO/SAM2及原有选择/复核流程）。不使用“80%掩膜落在理想CAD投影内”的检查。随后用OpenCV匹配已识别电池的图像块，不设置最少角点数量。
- 复用旧放置的稳定判据：至少4张新画面、时间跨度至少3秒、位移不超过10mm。RGB位移按仓口CAD投影换算，属于平面近似，不宣称为新的深度实测。识别模型耗时不计入稳定时间。
- 不修改抓取配置、容差、导航或队友的运动控制实现。

## 停止与总控

停止立刻请求右臂停止，保留当时的夹爪状态，不自动回零、再次松爪或下电。单独放置结束或停止后释放本任务控制权；异常回执保留供检查，不自动重放动作。控制器停止请求本身失败时仍保留待恢复状态。

`map.html` 的 place 模块复用同一个任务。总控提供运动令牌，放置子任务不释放总控令牌，由总控在整场完成、停止或无法恢复失败时归还手动控制。模型沿用该放置任务最近启动时保存的选择。

接口：GET `/api/cabinet-execution` 读状态；POST同一路径传 `{"op":"start","model":"demo"}` 或 `{"op":"cancel"}`。浏览器不能传轨迹、坐标、审批或放宽参数。旧圆圈下降放置及独立桥接探针保留原接口，不作为本页的实机执行入口。

## 验证边界

软件测试覆盖完整顺序、实际张爪反馈、取消、未知回执、控制权交接、错误目标及运动中的电池不能报成功。部署与页面读取不启动实机；机械精度和电池能否顺利入仓仍由现场验收。

# PLAN A：D435 粗定位 + D405 精定位自动抓取链路

> 本文把当前默认的 D405 精定位自动抓取方案定义为 **PLAN A**。
> PLAN A 不包括 D435 单帧 Plan B，也不包括纯定点 Plan C。

更新日期：2026-11-19

运行入口：`http://<ROG-IP>:9983/grasp-integration.html`

运行工作区：`/home/arx/arx-competition-control`

## 1. PLAN A 的用途

PLAN A 用 D435 完成大视野粗定位，驱动升降和右臂进入 D405 观察区域；随后用 D405、FoundationPose、电池 CAD 和点云计算抓取点，在预抓位置进行视觉精纠偏，最后插入提手孔、闭合夹爪、确认夹持、后退抽出并返回运输姿态。

正常状态机顺序：

```text
head
→ coarse_plan
→ coarse_execute
→ wrist
→ preview
→ pick_plan
→ approach_execute
→ wrist / preview / pick_plan（必要时循环纠偏）
→ insert
→ verify_hold
→ extract
→ carry
→ completed
```

## 2. 启动方式

1. 打开自动抓取二级页面。
2. 抓取模式选择 `D405 精定位（原方案）`。
3. 确认页面上的升降目标和右臂观察 Z。
4. 确认右臂、升降、夹爪和抓取通道无人且无临时障碍。
5. 勾选现场确认框并开始任务。

任务启动后取得自动运动控制权。任务运行期间，手动网页控制不能同时控制同一机器人运动；人工停止优先并中断本轮自动任务。正常完成后释放自动控制权。

当前配置值：

| 项目 | 当前值 |
|---|---:|
| 升降目标 | `3.0 rad` |
| 升降到达值 | `2.65 rad` |
| 右臂观察 Z | `700.5 mm` |
| 预抓距离 | `50 mm` |
| 夹爪闭合目标 | `0` |
| 夹持确认反馈范围 | `-1.5 ～ -0.5` |

## 3. 完整执行步骤

### 3.1 建立任务

- 申请自动任务控制权。
- 保存本轮 run ID、配置和执行状态。
- 启用 D435、D405 所需深度流。
- 读取右臂、左臂、升降和夹爪反馈。
- 后续动作、观测、规划和执行回执全部绑定到本轮任务。

### 3.2 D435 粗定位电池

1. D435 冻结一帧 RGB-D 和拍摄时刻的机器人反馈。
2. Grounding DINO 根据电池提示词产生候选框。
3. 排除位于 D435 固定机器人夹爪区域的候选。
4. SAM2 对候选进行分割，并结合深度计算电池表面三维位置。
5. 同一电池的整体框和局部框根据掩膜重叠和三维位置合并去重。
6. 本地结果明确时直接采用；本地没有合格候选或候选有歧义时才调用 Qwen。

自动链路的真实视觉入口是 `agent/perception_worker.py`。独立运行的 `vision/demo/pipeline.py` 是 Qwen 兜底/诊断入口，不能据此认定自动链路每次都调用 Qwen。

### 3.3 生成粗观察位置

- 根据 D435 得到的电池粗位置生成升降和右臂观察计划。
- 升降使用页面设定目标。
- 右臂观察 Z 使用页面设定值。
- 观察位 X/Y 根据本轮 D435 粗定位结果计算。
- 保存升降、左右臂反馈、观察轨迹及路径检查结果。

### 3.4 执行升降和预观察动作

1. 升降移动到目标高度并停稳。
2. 张开夹爪。
3. 右臂移动到 D405 预观察位置。
4. 等待机械臂停稳，建立新的 D405 观察阶段。

### 3.5 D405 精定位

- D405 冻结新的 RGB-D、关节和升降反馈。
- 重新识别和分割同一电池。
- 如果当前观察位没有找到电池，沿观察 Z 使用既有搜索序列：

```text
+10 → +20 → +30 → +40
→ 回到起点
→ -10 → -20 → -30 mm
```

该搜索只改变观察位置，不把搜索偏移直接当作抓取终点。

### 3.6 FoundationPose、点云和抓取点

1. 把 D405 图像、深度和电池掩膜交给 FoundationPose。
2. 使用完整电池 CAD 估计电池六维位姿。
3. 生成同一冻结帧对应的点云和几何结果。
4. 根据 CAD 计算提手孔中心对应的 TCP 终点 `T`。
5. 当前标定 TCP 是夹指尖，因此最终目标是让夹指尖到达 `T`。

### 3.7 生成预抓和插入路线

- 最终夹取终点为 `T`。
- 在 `T` 前方 `50 mm` 生成预抓点。
- 规划当前位置到预抓点的接近路线。
- 规划预抓点到 `T` 的插入路线。
- 复用现有 IK、关节限制、轨迹时序、立柱和路径检查。

### 3.8 到达预抓点

- 保持夹爪张开。
- 右臂移动到预抓点。
- 到达预抓点后不立即闭合夹爪，必须进入新的 D405 观察和精纠偏阶段。

### 3.9 预抓后的 D405 精纠偏

1. 在预抓位置重新冻结 D405 RGB-D。
2. 重新计算电池位姿和 `T` 点。
3. 比较当前 TCP 与目标抓取线。
4. 已在容差内时进入正式插入。
5. 超出容差时，同时分步修正 XYZ 和姿态，停稳后重新观察。

当前纠偏设置：

| 项目 | 当前值 |
|---|---:|
| XYZ 完成容差 | 每轴 `≤18 mm` |
| 姿态完成容差 | `≤5°` |
| 单次平移修正 | 三维总距离最多 `10 mm` |
| 单次姿态修正 | 最多 `5°` |

预抓后的精纠偏阶段没有固定三次观察上限；每次实际修正完成后都需要新画面验证。

### 3.10 插入并闭合夹爪

- 沿已规划的抓取线从预抓点前进到 `T`。
- 夹指尖到达提手孔中心后，下发夹爪闭合目标 `0`。
- 夹爪闭合动作完成不等于已经夹住电池，必须继续执行夹持确认。

### 3.11 夹持确认

- 读取新鲜的右夹爪反馈。
- 当前反馈位于 `-1.5 ～ -0.5` 时确认夹持。
- 该范围表示夹爪被电池提手阻挡并形成夹持，而不是完全空闭。
- 未确认夹持时不进入抽出阶段。

### 3.12 抽出电池

当前运行代码执行以下动作：

- 右臂保持夹取姿态。
- 夹爪保持闭合。
- 升降保持不动。
- 底盘复用现有导航定位、里程计和扫掠检查向后移动 `200 mm`。
- 底盘停稳后进入运输姿态阶段。

当前实现不是“右臂沿 X 抽出 155 mm + 底盘后退 100 mm”。

### 3.13 返回运输姿态

底盘停稳后，右臂返回：

```text
J1 = 0°
J2 = 0°
J3 = 0°
J4 = 0°
J5 = 0°
J6 = -90°
```

夹爪保持夹持，升降保持当前高度不动。

### 3.14 正常结束

- 流程状态设为 `completed`。
- 保存观测、计划、执行回执和日志。
- 关闭本轮视觉会话并恢复相机深度租约。
- 释放自动运动控制权，恢复手动控制。

## 4. 视觉选择逻辑

PLAN A 不是“DINO 只要有候选就一定选最高分”，也不是“每次都调用 Qwen”。当前自动链路顺序为：

```text
DINO 候选
→ 固定夹爪区域排除
→ SAM2 掩膜
→ 深度位置
→ 本地候选去重和目标关联
→ 明确：直接使用
→ 歧义/无合格候选：Qwen 兜底
```

预抓后的 D405 如果已有 FoundationPose 位姿，会优先把上一轮 CAD 位姿投影到新图，使用投影框和 SAM2 跟踪；跟踪失败后才回到候选识别和 Qwen 兜底。

## 5. 失败、停止和恢复边界

- 人工停止优先，停止后本轮任务不能自动续跑。
- 未知运动回执不会自动重发动作。
- 旧观察、旧计划或已变化的 TCP/标定不能继续执行。
- 未确认夹持不会进入抽出阶段。
- 正常失败会停止后续步骤并释放任务控制权；存在未知运动回执时页面会要求恢复处理。
- PLAN A 不会自动切换到 Plan B 或 Plan C。

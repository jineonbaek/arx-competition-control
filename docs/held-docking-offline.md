# D405夹持判断与自主找仓对位：离线实现

本轮已实现并联调RGB参考匹配、持物时序判断、阶段门控、局部停靠候选、持久化流程和模拟执行/停止仲裁。没有连接实机执行器、采集新图、修改在线服务或推送Git。

## 已接通的链路

`D405局部RGB参考匹配 → 夹持/姿态/相对滑移证据 → G09 → 找仓/底盘/升降/仓外对位门控 → 内存模拟执行器 → 新状态、新图和新许可 → 插入/释放的独立门控`

D435保留仓口主定位。D405不要求看全电池或电池仓，使用有足够特征的电池局部区域与独立夹指锚点。算法采用角点、双向光流、局部仿射鲁棒拟合和光度一致检查，在夹爪参考系内比较变化，正常共同运动不当成滑移。

它是参考驱动的保守RGB识别器，不是已经训练并验收的通用电池网络。需要独立确认的正确夹持参考、关键区域标注和身份绑定。不能拿第一帧自行当正确参考；没有参考或关键特征不清楚时输出unknown。二维图像匹配不提供未观测的深度、完整6DoF、毫米开度或夹持力。实拍泛化、现场误差上界与可靠承载仍未验证。

`HeldBatteryMonitor`需要不同曝光的连续证据、配对夹爪反馈和合格承载/不可观测轴证据，才能输出**仿真范围内**的eligible。承载证据同时绑定完整相机/TCP/电池/抓取身份hash及参考RGB/区域hash。换标定、换物或换参考不能沿用旧许可；滑移和同次抓取的参考重置不能被静默吸收。

## 门控与打断

- 采用阶段依赖表。没有目标时可进行已具备其他证据的有限搜索；只读诊断和停止请求不会被缺失运动证据拦住。
- 底盘SDK到SI映射、控制级里程计、障碍覆盖、正常路径与停止包络、升降标定、关节/退路等证据缺失时，对应动作拒绝。
- 粗对位不会解锁入仓。入仓需要经验证的端到端误差上界严格小于实际净距减保留量；重投影误差或名义外参不能代替。
- `DockingPlanner`给出限定区域内的底盘/升降候选并按净距、关节余量和移动代价排序，需要注入运动学/扫掠检查。内置演示的检查来自**合成场景真值**，不声称已证明真实双臂、负载、环境或停止距离。
- 运动段期间持续通过step/观察事件监督证据与许可租期；失效、丢失、过期或超时锁存停止。迟到完成回执可以记录，但不能使流程重新运行。
- 人工停止/父任务取消优先。停止请求不依赖正常运动门控；交权要有停止之后、连续且不同的新反馈。服务成功或零目标速度不等于停稳。
- 暂停恢复是显式操作，重新取得代次、实际位置、里程及新观测；不重放旧轨迹，不重置累计预算。未决动作或释放结果未知保持恢复锁。
- 入仓接合状态单独落盘。可能进入仓口时，不能因重新看到红框就回到底盘/升降对位。
- 正常松爪采用release_progress合同，不把预期张开/空爪当成运输滑移。空爪撤回还要检查释放证据；新视觉仍看见电池在夹爪中时会拒绝空爪撤回。

## 实现位置

| 模块 | 作用 |
|---|---|
| `agent/held_rgb.py` | 文件RGB的局部电池/夹指参考匹配，不申请深度或打开相机 |
| `agent/held_battery.py` | 多帧夹持、姿态、滑移、身份和时效判断 |
| `agent/cabinet_gates.py` | G01–G20的阶段门控、误差预算和释放分支 |
| `agent/cabinet_docking.py` | 有界候选及累计搜索/纠偏里程预算 |
| `agent/cabinet_simulator.py` | 独占代次、一次性段、TTL、独立停止与停稳交权，只有内存事件 |
| `agent/cabinet_autonomy.py` | 多帧D435跟踪、G09接入、持久化阶段、人工暂停/恢复和父子控制权 |
| `agent/cabinet_replay.py` | 合成场景联调与真实历史图像报告 |
| `scripts/replay_cabinet_autonomy.py` | 离线入口，无ROS、网络或实机控制传输 |

运行器只接受精确类型`SimulationExecutor`，不能换成真实Controller或继承的控制适配器。所有报告和段都带`mode=offline`及`executable=false`。本轮没有修补/替换在线Controller、C++手柄仲裁或驱动停止路径；之前发现的实机接管/停止集成缺口仍是未来接硬件的阻断条件。

## 使用

在主机独立目录使用现有虚拟环境：

```bash
cd /home/arx/arx-place-integration
/home/arx/arx-competition-control/.venv/bin/python scripts/replay_cabinet_autonomy.py --demo --output reports/held-docking-demo
```

合成演示覆盖：完整仿真通路、滑移、遮挡、精度不足和人工停止。D405使用实际RGB算法；D435目标及设备/障碍证据为明确标记的仿真真值。仿真流程完成不等于实物放置成功。

历史数据回放：

```bash
python scripts/replay_cabinet_autonomy.py \
  --d435-frame /path/to/saved-d435-frame.npz \
  --d405-image /path/to/saved-d405.jpg \
  --d405-meta /path/to/saved-d405.json \
  --output reports/held-docking-recorded
```

可选`--d405-reference qualified-reference.npz`。该文件包含`rgb`、`battery_mask`、`jaw_mask`、可选`empty_rgb`以及JSON字符串`identity`、字符串`reference_kind`。identity必须包含reference_id、camera=d405、serial、handeye_sha256、tcp_sha256、battery_sha256、grasp_id；所有hash绑定实际参考/标定，不能以当前图片自动生成合格基准。允许的kind为synthetic或annotated_archive，始终只用于离线验证。

输出`index.html`、`report.json`及预览图，不捕获相机。历史曝光时间保留并显示实际帧龄；单帧和没有参考/新夹爪反馈的数据不能获得可靠持物资格。本轮真实D435历史帧可以识别仓口并生成原有几何预览；真实D405历史图像因缺合格夹持参考，结果为unknown，G09及运动门控保持阻断。

## 验证边界

验收CSV仍是58项设计要求，不能把它们等同于58个实物测试已通过。新增单元与联调测试验证本轮已实现的离线合同，另有对照表标明只覆盖门控合同/尚需真实标注数据或硬件集成的部分。

后续仍需：正确夹持实拍参考及遮挡/对称/夹偏数据集、真实运动学与完整负载停止包络检查器、控制级里程计与SI标定、实际承载/支撑与窄仓口端到端误差证据、真实控制网关与跨来源停止仲裁。它们不由合成测试自动认证，也不由人工一键覆盖。

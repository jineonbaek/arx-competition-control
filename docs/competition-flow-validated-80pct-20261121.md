## 3. 开始比赛与准备动作

### 步骤 1：建立比赛任务

1. 在比赛页面确认本轮作业区无人且无临时障碍，点击“开始比赛”。
2. 创建独立的 `competition-...` 任务编号，记录阶段、请求编号和执行回执。
3. 申请整场比赛控制权，后续按阶段在导航与机械臂作业之间交接。
4. 预热抓取视觉，供到达无人机位置后复用。

### 步骤 2：左右臂进入准备姿态

下发并等待现有固定点位到位：

| 机械臂 | 点位 | J1～J6，单位 ° |
|---|---|---|
| 左臂 | 固定点位 2 | `0, 0, 90, 0, 0, 0` |
| 右臂 | 避障预设位 | `0, 0, 65, -65, 0, 0` |

左臂使用固定点位 2 的保持动作；右臂避障预设动作保持原有夹爪状态。到位沿用每个关节 ±2° 的固定点判定。

### 步骤 3：预置抓取升降高度

使用抓取页面保存的升降设置。当前页面加载值为：

- 指令目标：`12.52 rad`。
- 原有向下取整接受值：`12.0 rad`。

比赛在双臂准备完成后下发升降目标，再启动取物导航；没有在这里新增一个等待升降完成后才允许导航的阶段。抓取正式开始前，PLAN F 仍会复用现有升降准备逻辑，确认其已到可观察高度。

## 4. 第一段导航：到无人机取物区

### 步骤 4：启动并跟随导航路线

1. 比赛总控通过 `NavigationSession` 接入导航队友已有的任务接口。
2. 导航端执行当前路线，负责定位、路径跟随、正常导航避障和停车。
3. 到达取物工作区后，导航端提供本轮 `point_1` 到访通知。
4. 9983 核对本轮任务和到访身份，收到有效到点、停稳交接后完成 `navigate_pick`。

### 步骤 5：切入已有抓取任务

比赛的 `pick` 阶段直接调用已有的 `BatteryTask.start_owned(...)`，使用比赛持有的作业控制权，运行同一个自动抓取流程。

**比赛抓取复用二级抓取页面的执行核心；比赛总控没有另写一套识别、夹取和抽出动作。**

## 5. 抓取任务内部：当前 PLAN F 的完整步骤

### 步骤 6：确认升降已到可观察高度

1. 读取当前升降反馈，按保存的抓取目标和原有向下取整规则判断。
2. 已达到接受值时继续，不重复升降。
3. 未达到时，复用已经下发的升降动作；没有预先下发动作时才补发目标。
4. 完成现有到达、停稳处理后，进入首轮 D405 观察。

因此，比赛提前升降和二级页面单独启动都接到同一段升降准备逻辑。

### 步骤 7：在右臂当前避障位用 D405 观察

1. D405 冻结本轮 RGB-D，同时记录对应的关节和升降反馈。
2. 此时右臂已由比赛准备阶段放到避障预设位。
3. PLAN F 使用该视角完成首轮定位，已取消固定 `700.5 mm` 预观察高度的移动环节。

当前 PLAN F 的这段抓取不依赖 D435 找到无人机上的电池。D435 仍用于后续柜前视觉定位等其他任务。

### 步骤 8：识别和分割电池

1. Grounding DINO 用当前加载的提示词生成候选。
2. SAM2 分割候选，并结合深度和已有的本地选择逻辑确定目标。
3. 本地结果明确时直接使用；需要语义判别时调用已有 Qwen 兜底。
4. 提示词管理区所选方案会随抓取任务实际加载。

本次成功抓取加载的是“完整电池方案（历史）”，其 DINO 提示词为：

```text
a rectangular drone battery pack with a protruding handle at one end, partially inserted into a drone.
```

把手方案仍保留在页面可选列表中；本文记录本次成功链路实际采用的电池方案。

### 步骤 9：由电池 CAD 和深度计算夹取目标

1. 使用 D405 RGB-D、电池掩膜、相机参数和电池 CAD 进行 FoundationPose 位姿估计。
2. 结合当前机器人反馈和手眼标定，计算机器人坐标系下的电池位姿。
3. 根据 CAD 上的夹取几何确定最终目标 `T`。
4. TCP 使用已标定的夹指尖位置，后续规划以夹指尖到达目标为准。

### 步骤 10：生成预抓和插入路线

1. 在最终夹取点 `T` 前方 `50 mm` 生成预抓点。
2. 生成当前位置到预抓点的接近轨迹，以及预抓点到 `T` 的插入轨迹。
3. 复用已有 IK、关节限制、运动时序与路径检查。

### 步骤 11：张开夹爪并移动到预抓点

1. 下发张爪，指令使用当前配置的张开值 `-3.14`。
2. 根据原有反馈条件确认张开，再执行右臂接近轨迹。
3. 轨迹结束后，用实际 TCP 反馈检查预抓位置和停稳状态。

当前首次预抓点验收采用 **XYZ 每轴 ±10 mm，旋转向量各分量 ±3°**。这个调整在首次预抓到位阶段生效，张爪前的位置检查、后续纠偏运动和最终插入保留原要求。

### 步骤 12：预抓后重新拍照和精纠偏

1. 到预抓点后，D405 重新冻结一帧 RGB-D。
2. 重新估计电池位姿和 `T`，比较当前 TCP 与抓取线。
3. 满足原有视觉纠偏完成条件时，生成正式插入计划。
4. 需要纠偏时，执行现有的平移、姿态修正，再重新观察。

原有视觉精纠偏参数：XYZ 每轴 `18 mm`、姿态角 `5°`；单次平移修正最多 `10 mm`、单次姿态修正最多 `5°`。这些值与“首次预抓到位验收”的 10 mm／3° 是不同阶段的比较。

### 步骤 13：插入提手并闭合夹爪

1. 沿已规划的抓取线从预抓点前进到 `T`。
2. 最终插入仍采用 XYZ 每轴 `±5 mm`、旋转向量各分量 `±1.5°` 的到位条件及原有停稳要求。
3. 到位后下发夹爪闭合目标 `0`。
4. 等待原有闭合反馈过程完成，再进行夹持确认。

### 步骤 14：确认夹持

读取夹爪实际反馈，使用现有的 `-1.5～-0.5` 夹持确认范围。确认后进入 `HOLD_CONFIRMED`，再执行抽出。

“下发闭合目标 0”和“确认夹住电池”是两个连续步骤。

### 步骤 15：底盘后退抽出电池

1. 右臂保持抓取姿态、夹爪保持夹持，升降保持当时高度。
2. 使用现有 ROS 底盘调度和导航定位，向后撤出 `200 mm`。
3. 停止等待、后退运动和结束输出使用同一个导航来源会话。
4. 完成已有的实测停车确认，再进入右臂返回动作。

当前这一步是底盘后退抽出，不是先让机械臂抽回 155 mm。当前 `8c1ab702` 源码对自动抓取撤出段跳过 costmap 检查，保留定位依据和停车确认；正常导航仍由导航端负责。

### 步骤 16：右臂返回运输姿态，结束抓取

底盘撤出停稳后，右臂执行：

```text
J1 = 0°
J2 = 0°
J3 = 90°
J4 = -70°
J5 = 0°
J6 = -90°
```

夹爪继续保持夹持，返回过程中升降保持当前高度。关节到位沿用约 ±2° 的现有条件。

回到运输姿态后，抓取任务形成 `CARRY_READY` 回执，流程标记 `completed`。

**“底盘撤出后，右臂回运输姿态”这个实际动作就在抓取任务内部。**

## 6. 运输确认、降低升降及第二段导航

### 步骤 17：比赛 carry 阶段核对回执

这一阶段复用上一阶段的完成回执，不再发送第二次右臂运输动作。

### 步骤 18：准备携物导航并通知导航端

1. 进入 `navigate_place` 时，比赛从机械臂作业切回导航控制模式。

3. 向升降下发放置准备目标 `0 rad`，此处不阻塞等待升降完成。
4. 通过原有 `complete_visit(...)` 发送 `point_1` 作业完成消息，包含 `control_released=true`、`navigation_ready=true`。
5. 导航端按原交接协议确认，继续执行到柜前的剩余路线。

因此，在比赛里，通知导航继续是在右臂完成运输姿态之后；降低升降的指令在进入这段携物导航时下发。

### 步骤 19：携物通过障碍区并到柜前停稳

1. 导航端负责携物路径和正常导航避障。
2. 右臂保持运输姿态，夹爪保持夹持；升降执行前面已下发的降低目标。
3. 到达柜前 `point_2`，导航端提供本轮到点、停稳交接。
4. 比赛记录 `navigate_place` 完成，准备进入柜前放置。

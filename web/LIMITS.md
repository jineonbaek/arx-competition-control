# 方舟无限限位依据

本文件只适用于方舟无限。TH 机械臂仅作为网页交互参考，不使用它的角度、速度或 SDK 参数。

## 六轴目标范围

厂家 ROS2 手册第 2 页的“软件限位”和 X5 官方 README 的关节范围图片一致：

| 轴 | 厂家软件范围 rad | 网页/后端范围 ° |
| --- | --- | --- |
| J1 | -1.57 .. 1.57 | -89.9 .. 89.9 |
| J2 | -0.1 .. 3.6 | -5.7 .. 206.2 |
| J3 | -0.1 .. 3.0 | -5.7 .. 171.8 |
| J4 | -1.29 .. 1.29 | -73.9 .. 73.9 |
| J5 | -1.48 .. 1.48 | -84.7 .. 84.7 |
| J6 | -1.74 .. 1.74 | -99.6 .. 99.6 |

换算后向内取整到网页的 0.1° 精度，避免舍入扩大厂家范围。左右臂分别保存同一份厂家单臂范围；安装坐标、零位、双臂与车身干涉尚未通过实机验收，verified 仍为 false。

J2/J3 的 -0.1 是厂家软件列为防止解算失效保留的范围，不是本项目证明机械止挡允许负角度。没有验证时不下发动作。

手册第 6 页建议联调设置角度不要超过 ±0.1。本项目暂把这个建议转为目标与新鲜反馈的单次差值限制 5.7°；这是项目保守策略，不是厂家定义的通用单步限制，也不能代替速度/加速度限制。正常任务范围以后需经现场验收调整。

## 夹爪

本机已有启动配置使用 v2_pos_control.launch.py，arm_end_type=2，对应 X5-2025/AC one；尚未以实物验收。

ROS2 参数表给 AC one 夹爪 -3.4..0.1，备注 0 为闭合、0.1 为夹紧；Python SDK 手册和 README 给 X5-2025 -3.14..0。因此网页取交集 -3.14..0，打开目标 -3.14、闭合目标 0，不设置夹紧过驱 0.1。

网页走 normal RobotCmd，gripper 原值直接传给 setCatch；不套用 VR 模式的 0..5 再乘 -3.4/5。真实开闭端点、夹持力和毫米宽度没有验收，控制仍禁用。

## 升降

厂家高度手册写明 SDK 范围 0..20，单位为电机累计角度 rad。用户指定本机网页上限为 18，所以保持 0..18 rad。此网页配置不修改底层驱动，也不证明重新归零后的物理高度和停止距离。

## 尚不能按厂家明确数值配置的项

- 底盘：轮速手册要求发布频率 >=10Hz，示例 chx=0.6 不是额定上限。没有确认的本机安全线速度、转速、加速度时，不填猜测值。
- 静态查看 LIFT ROS2 SDK 的 RobotType=0 分支，内部 max_vel_x/y/z 常数为 0.92/1.6/1.8，setChassisCmd 会钳位并归一化；这是库的编码行为，不等于本机经验证的 m/s、rad/s 安全工况，暂不写入执行限值。
- 关节速度/加速度：没有核实的公开配置值，不能把电机协议最大值或接口里的 arx_x 参数当作速度限位。
- TCP：没有当前安装的安全 XYZ 区域；臂展不是可直接使用的三轴范围。末端路径的关节限位、双臂/车身碰撞尚未接入，TCP 保持禁用。

未知值保留 null，所有 verified 与 execution_enabled 保持 false。

源链接、精确原始数值与版本记录见 config/limit-sources.json。官方 X5、ARX_X5、LIFT 的远端默认分支已只读核对，与工作区当前 commit 一致；没有更新或修改厂家仓库。

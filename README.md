# Plan C：纯定点自动夹取链路

## 定义

本工作区中的“纯定点自动夹取链路”统一定义为 **Plan C**。

Plan C 使用预先记录的三个固定参数执行抓取：

1. 底盘升降目标值（rad）；
2. 右臂预夹取点（六轴关节角，rad）；
3. 右臂夹取点（六轴关节角，rad）。

它不使用 D435、D405、Grounding-DINO、SAM2、FoundationPose、点云、CAD 目标位姿 T 点或视觉纠偏。代码内部使用 `vision_mode=fixed` 表示该模式，但产品和本文档统一称为 **Plan C**。

Plan C 目前只接在 9983 的自动抓取二级页面中，用于独立调试和实机验证；没有替换 Plan A、Plan B，也没有接入比赛总任务的默认抓取步骤。

## 与 Plan A / Plan B 的区别

| 模式 | 目标来源 | 相机和视觉 | 运行中纠偏 |
| --- | --- | --- | --- |
| Plan A | D435 粗定位后由 D405 精定位 | D435 + D405 + FoundationPose | 有 |
| Plan B | D435 单帧定位和抓取规划 | D435 + FoundationPose | 无 D405 精纠偏 |
| **Plan C** | 已保存的升降值、预夹取点和夹取点 | **全部不调用** | **无** |

Plan C 依赖底盘每次停在相同位置、无人机和电池安装位置可重复。它不会在运行中自动切换到 Plan A 或 Plan B。

## 点位记录

### 记录内容

页面提供三个 Plan C 参数：

- `Plan C 底盘升降目标（rad）`
- `Plan C 预夹取点 → 记录当前位置`
- `Plan C 夹取点 → 记录当前位置`

点击“记录当前位置”时，后端读取右臂最新反馈并保存六个关节角。预夹取点和夹取点共用同一个 Plan C 升降目标；后一次记录时输入的升降值会成为当前保存值。

### 记录步骤

1. 确认当前没有正在运行的自动任务。
2. 使用现有手动控制把升降和右臂移动到预夹取姿态。
3. 在自动抓取页面填写 Plan C 升降目标，点击预夹取点的“记录当前位置”。
4. 保持同一升降设定，把右臂移动到实际夹取姿态。
5. 点击夹取点的“记录当前位置”。
6. 页面应显示两个已保存的六轴点位。

记录点位要求右臂反馈为新鲜数据，并且每个点恰好包含六个有限数值。自动任务运行期间不能覆盖示教点。

## 完整执行链路

Plan C 的实际执行顺序如下：

```text
选择 Plan C 并确认环境无人、无临时障碍
→ 读取已保存的升降目标、预夹取点和夹取点
→ 取得自动任务运动控制权
→ 生成升降＋预夹取计划
→ 复用现有路径审查
→ 升降到目标并停止
→ 张开夹爪
→ 右臂移动到预夹取点并稳定
→ 生成预夹取点到夹取点的六轴轨迹
→ 复用现有路径审查
→ 右臂移动到夹取点
→ 下发夹爪闭合目标 0
→ 按现有夹爪反馈范围确认已经夹持
→ 底盘沿自身后方后退 200 mm 并停车
→ 右臂返回运输姿态：J1～J5 = 0°，J6 = -90°
→ 夹爪继续夹持，升降保持不动
→ 任务完成并归还控制权
```

### 1. 启动检查

页面启动 Plan C 时会检查：

- 模式为 Plan C；
- 预夹取点和夹取点都已记录；
- 升降目标存在；
- 操作者已勾选“右臂、升降和夹取通道无人且无临时障碍”；
- 当前没有其他自动任务或待恢复任务。

Plan C 不会启用任何相机深度流，也不会创建视觉识别会话。

### 2. 升降、张开夹爪并到预夹取点

后端根据当前左右臂和升降反馈生成固定粗对位计划：

- 升降目标使用保存值；
- 右臂终点使用保存的预夹取六轴点位；
- 左臂不执行新动作，但沿用现有双臂与中央立柱几何检查；
- 复用现有轨迹时间、反馈新鲜度、到位和停止逻辑。

执行顺序固定为：升降运动 → 升降停止 → 张开夹爪 → 右臂到预夹取点 → 等待稳定。

### 3. 从预夹取点运动到夹取点

到达预夹取点后，程序读取最新右臂和升降反馈，再生成到保存夹取点的六轴关节轨迹。该计划复用当前 TCP 标定、轨迹时间计算、中央立柱 CAD 几何检查和现有本地路径审查。

Plan C 在这里不会重新拍照、重新识别或进行 XYZ / 姿态视觉纠偏。

### 4. 闭合夹爪并确认夹持

右臂到达夹取点并稳定后，程序只下发一次夹爪闭合目标：

```text
gripper_target = 0
```

随后复用现有 `verify_hold`，通过夹爪反馈确认夹持状态。当前配置的夹持确认范围是 `[-1.5, -0.5]`。

### 5. 底盘后退 200 mm

夹持确认后执行现有 `stow_for_carry`：

- 复用导航队友已有的底盘位姿、里程计、代价地图、轨迹跟踪和停车逻辑；
- 目标是沿底盘自身后方后退 `0.200 m`；
- 停车后使用已有反馈确认底盘停止。

**当前 Plan C 没有单独执行右臂沿 X 轴抽回 155 mm 的动作。当前链路是在夹持确认后直接让底盘后退 200 mm。**

### 6. 返回运输姿态

底盘停车后，右臂沿现有平滑轨迹返回：

```text
J1 =   0°
J2 =   0°
J3 =   0°
J4 =   0°
J5 =   0°
J6 = -90°
```

返回过程中：

- 夹爪保持夹持，不发送张开命令；
- 升降保持当前高度，不发送新的升降目标；
- 使用现有右臂轨迹和到位判定。

## 沿用的现有判定

Plan C 没有增加新的容差、门槛或判定。它复用原自动夹取链路已有的检查。以下是当前代码中的实际值，写在这里仅用于记录，不代表 README 新增了这些规则：

| 项目 | 当前行为 |
| --- | --- |
| 升降输入范围 | `1–18 rad` |
| 升降成功值 | 对输入值向下取整，例如 `6.6 → 6.0` |
| 预夹取/夹取点 | 六轴、有限数值、需要新鲜反馈 |
| 预夹取路径 | 复用升降扫掠、双臂/中央立柱 CAD 检查和环境确认 |
| 夹取路径 | 复用 TCP、中央立柱 CAD、IK/轨迹和环境确认 |
| 轨迹插值数学上界 | 位置 `≤ 2 mm`，姿态 `≤ 0.7°` |
| 夹爪闭合目标 | `0` |
| 夹持确认反馈 | `[-1.5, -0.5]` |
| 底盘后退目标 | `200 mm` |
| 底盘停车后的既有距离确认 | 实测后退量大于 `200 mm` 且小于 `400 mm` |
| 运输姿态 | J1～J5 为 `0°`，J6 为 `-90°` |

如果任务完成或能够确认停止，后端归还 9983 手动控制权。如果存在尚未清理的运动回执，后端沿用现有恢复机制保留控制权并标记 `recovery_required`，不会自动重放运动。

## 使用方法

1. 打开 `http://<ROG-IP>:9983/grasp-integration.html`。
2. 在“抓取模式”选择 **Plan C 纯定点夹取**。
3. 填写 Plan C 底盘升降目标。
4. 分别记录预夹取点和夹取点；已记录点会持久化保存。
5. 确认底盘已经停在示教时的抓取位置，无人机、电池和现场布置与示教条件一致。
6. 勾选环境确认框。
7. 点击“开始实机流程”。
8. 通过页面实时日志查看当前阶段；停止按钮沿用原自动任务取消逻辑。

## 限制

- Plan C 是固定点链路，不具备视觉识别和自动纠偏能力。
- 底盘停车位置、升降零点、机械臂标定、无人机位置或电池安装位置发生变化后，应重新示教。
- 两个点位任意一个未记录时，Plan C 会拒绝启动。
- Plan C 不会自动回退到 Plan A 或 Plan B。
- 当前链路夹持后直接后退底盘 200 mm，不包含右臂 155 mm 抽出步骤。

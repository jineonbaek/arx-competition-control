# 右臂 D405 逐点标定采集

入口 /handeye.html。D405 固定在右臂，标定板固定在工作台。底盘、升降及左臂停稳，右臂由本页独占操作。当前交付范围到逐点采样和样本判定。

生成候选时记录右臂实测关节为本次起点。12 个候选是围绕该起点的小角度腕部偏移，J1 保持起始角。每个候选按驱动关节插值在 DIY URDF 中计算右臂及夹爪包围盒到中央立柱包围盒的距离下界。立柱水平包围盒额外扩大 10 mm，夹爪覆盖完整开合行程。相邻采样姿态之间按关节角变化与最大回转半径扣除位移余量。下界需大于 20 mm，并通过关节软件限位及 J1 ≥ −35.8° 的本机保守约束。检查只覆盖右臂/夹爪与中央立柱，不含 D405 外壳、另一只臂、工作台或外部障碍。升降使用名义比例。

候选被跳过时页面列出原因。通过时页面模拟当前位置到该点的路径。操作员在当前会话确认模型方向及现场状态后，逐点点击执行。服务端校验同一会话、单次确认票据、起始反馈、停稳及完整路径，再通过控制台现有 X5 接口下发这一点。执行后监测右臂及升降；超时、中断及不可达不自动重试或回零。停止按钮只作用于本次采集及右臂的软件停止。采完不会自动执行下一点。

原地试采和运动采样均使用 D405 已有的 640×480 彩色原始帧和该活动配置的厂家内参。使用板上同一枚 ArUco 的字典、ID 和黑色外框实际边长；留空可先预览路径。停稳后检查三帧连续检测、重投影 RMS ≤2 px、标记位姿稳定、图像与关节时间差 ≤0.20 s。通过时图像和成对变换保存在 web/hardware/runtime/handeye/<session>/point-XX/。记录的末端变换是 body4_from_right_link26，由实测关节和 CAD 正运动学得出；相机变换是 camera_from_marker。单样本“可用”表示通过这些筛选，独立姿态和最终手眼精度仍需验证。查看页面和预览候选沿用主控台的深度设置。程序试采或执行单点时优先请求 D405 仅彩色模式，结束或失败后释放并恢复原手动设置。

运动采样将候选作为参考。六轴最大目标偏差需小于等于本次最大单轴行程的 25%，且不超过 2°。用于新运动样本的行程至少 0.5°。到达参考附近后需连续停稳至少 0.40 秒，关节波动不超过 0.18°。每张图匹配停稳窗口内时间最近的实测关节反馈，并用它计算末端位姿。失败记录显示偏差最大的关节、目标和实测值。
